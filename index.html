ABOUT

How I work

My background combines implementation with requirements work, architecture, testing, and product-oriented design. I am most interested in work where I can understand the user or operational problem, translate it into clear system behavior, and stay close enough to implementation to verify that the result actually works.

I use AI-assisted development tools as part of my workflow, but I treat generated code as code I am responsible for understanding, testing, and maintaining.
